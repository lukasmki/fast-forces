Reactions and EVB
=================

From a reaction SMILES to a two-state EVB surface.
:mod:`~fastforces.reaction` builds the states and stationary points,
:mod:`~fastforces.coupling` fits the off-diagonal term, and
:mod:`~fastforces.evb` evaluates the result.
